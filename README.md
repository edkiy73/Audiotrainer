# Слепая расшифровка — PWA

Тренажёр аудирования: слушаешь короткими отрезками, записываешь на слух, раз в блок сверяешься с оригиналом.
Статика, бэкенда нет. Опционально — один Cloudflare Worker для автозагрузки субтитров.

## Что заливать на сервер
- `index.html` — приложение целиком
- `sw.js` — service worker, офлайн-кэш
- `manifest.webmanifest` — манифест PWA
- `icon.svg`, `icon-192.png`, `icon-512.png` — иконки

`worker.js` и этот README на сервер не нужны.

## Деплой
1. Распаковать в папку, например `/blind/`. Пути относительные, подпапка работает как есть.
2. Открывать по **https** — иначе не встанет service worker и приложение не поставится на экран.

Nginx:
```
location /blind/ {
    try_files $uri $uri/ /blind/index.html;
}
location = /blind/sw.js       { add_header Cache-Control "no-cache"; }
location = /blind/index.html  { add_header Cache-Control "no-cache"; }
```

После правок в `index.html` подними версию кэша в `sw.js`: `blindtr-v2` → `blindtr-v3`.
Иначе у тех, кто уже поставил приложение, останется старая версия.

## Автозагрузка субтитров (необязательно)
YouTube не отдаёт субтитры прямо в браузер — мешает CORS. Нужен свой мини-прокси.

1. dash.cloudflare.com → Workers & Pages → Create → Worker
2. Вставить содержимое `worker.js`, Deploy
3. В приложении: «Настроить автозагрузку субтитров» → вписать адрес вида `https://имя.workers.dev`
4. Кнопка «Загрузить субтитры» начнёт работать, адрес сохранится в браузере

Бесплатного тарифа хватает с запасом: 100 000 запросов в день.
Если YouTube поменяет внутренние ручки и воркер отвалится — субтитры всегда можно вставить руками,
приложение от прокси не зависит.

## Два источника звука
- **YouTube** — нужен https-хостинг (по file:// плеер отдаёт ошибку 153)
- **Файл с устройства** — видео или аудио играет из памяти браузера, работает офлайн и по file://
  Между сессиями файл не сохраняется, ответы — сохраняются

## Две стратегии нарезки
- **По фразам** (по умолчанию) — граница отрезка ищется в паузе речи или на знаке конца предложения
  рядом с целевой длиной. Слова и фразы не рвутся, длинная тишина пропускается.
- **Ровно по секундам** — жёсткая сетка, как в исходной методике.

## Локальная проверка
```
python3 -m http.server 8000
```
и открыть http://localhost:8000
