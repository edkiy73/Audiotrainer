Слепая расшифровкааудирование без подсказок

Слушай отрезками. Сверяйся раз в минуту.

Приложение режет дорожку на короткие отрезки по границам фраз, прячет текст и возвращает его только на сверке.

Источник звука
Играет прямо из памяти браузера, никуда не загружается. После перезагрузки страницы файл нужно выбрать заново — ответы сохранятся.
Файл .srt или .vtt можно перетащить в окно.
Взять субтитры руками
  1. Открой видео на YouTube, под ним «…ещё» → «Показать расшифровку видео».
  2. Выдели весь текст расшифровки и скопируй.
  3. Вставь сюда. Метки времени можно оставить — парсер понимает оба варианта.
Настроить автозагрузку субтитров
  • YouTube не отдаёт субтитры прямо в браузер — нужен свой мини-прокси.
  • В архиве лежит worker.js: заведи бесплатный Cloudflare Worker, вставь код, задеплой.
  • Адрес воркера вида https://имя.workers.dev впиши ниже — кнопка «Загрузить субтитры» начнёт работать.
