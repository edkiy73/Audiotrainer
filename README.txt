English Trainer — установка как приложение
==========================================

ЧТО ВНУТРИ
  index.html               само приложение (весь код и контент в одном файле)
  manifest.webmanifest     описание приложения: имя, иконки, режим запуска
  sw.js                    офлайн-режим и возможность установки
  icon-*.png               иконки для домашнего экрана

КАК УСТАНОВИТЬ
  1. Залей все файлы в одну папку на хостинг.
     Важно: обязательно по https, иначе не будет ни установки, ни микрофона.
  2. Открой адрес этой папки в Chrome на телефоне.
  3. Меню (три точки) -> "Установить приложение" или "Добавить на главный экран".
  4. Приложение появится на домашнем экране с иконкой и будет
     запускаться без адресной строки, как обычное приложение.

  На iPhone: открыть в Safari -> "Поделиться" -> "На экран Домой".

ЧТО РАБОТАЕТ БЕЗ ИНТЕРНЕТА
  Всё, кроме двух вещей:
   - распознавание речи в голосовом режиме (нужен интернет);
   - кнопка "Открыть Gemini" в разговорах с ИИ.
  Уроки, дриллы, аудирование, повторы и прогресс работают офлайн.

КАК ОБНОВЛЯТЬ
  1. Заменил index.html на новую версию?
  2. Открой sw.js и поменяй строку с версией, например:
        const CACHE = "english-trainer-v1";
     на
        const CACHE = "english-trainer-v2";
  3. Залей оба файла. При следующем запуске телефон подтянет свежую версию.

  Если этого не сделать, телефон может показывать старую версию из кэша.

ГДЕ ХРАНИТСЯ ПРОГРЕСС
  В памяти браузера на телефоне, привязан к адресу сайта.
  Он не пропадёт при обновлении файлов, но пропадёт, если очистить
  данные сайта в браузере или сменить адрес, по которому лежит приложение.
